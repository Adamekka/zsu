# Dataset selection assignment

Source: course screenshot supplied on 10 November 2026, "Project 2: Dataset Selection", lecturer HANO261. Deadline: 11 November 2026 at 17:45.

Choose a dataset for supervised learning that differs from Project 1 and meets these criteria:

- At least 2,000 rows.
- At least 10 distinct usable features, excluding targets, row IDs and exact duplicate columns.
- At least 3 continuous numerical variables and 2 categorical variables.
- Raw data requiring active preprocessing, such as handling missing values, encoding strings or parsing dates.
- No standard toy datasets, including Titanic, Iris, basic MNIST or Boston Housing. A thesis dataset is allowed if it meets the thresholds.

Kaggle is recommended, but other public sources and custom datasets are allowed.

Submit a document containing the dataset name, source URL or citation, row count, usable feature names and types, target variable name, and expected cleaning operations. Include the data or at least a sample if it is not public.

Jupyter Notebook or Markdown is preferred. A Git repository and first commit are optional; the document must still be uploaded to the course submission page.
